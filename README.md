# VocabDeck — موقع إنشاء بطاقات Anki

هذا مشروع ويب يحوّل صور قوائم الكلمات أو الكلمات التي تكتبها إلى بطاقات Anki من نوع **الصورة أولًا ثم الكلمة**. ينشئ ملف `.apkg` واحدًا يحتوي على البطاقات والوسائط المتاحة.

## ما الذي يفعله؟

- قراءة الكلمات الإنجليزية من صور الصفحات باستخدام Gemini.
- إدخال الكلمات يدويًا.
- توليد مستوى CEFR (A1–C2)، ومعنى إنجليزي، وجملة مثال، وعبارة بحث عن صورة.
- البحث عن صور عبر Wikimedia Commons مع إضافة رابط المصدر إلى البطاقة عند توفر صورة.
- محاولة توليد نطق إنجليزي عبر Google TTS، ثم محاولة استخدام تسجيل من قاموس إنجليزي عند فشل المصدر الأول.
- مراجعة الكلمات وتعديلها قبل إنشاء البطاقات.
- تنزيل `.apkg` مع الصور والصوت الناجحين، أو تنزيل CSV للنصوص فقط.

## التشغيل على Linux Mint أو Windows

تحتاج إلى Python 3.10 أو أحدث واتصال بالإنترنت وقت إنشاء المحتوى والوسائط.

1. فكّ ملفات المشروع في مجلد.
2. افتح الطرفية داخل مجلد `gemini-vocab-web`.
3. أنشئ بيئة وثبّت المتطلبات:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

على Windows، فعّل البيئة باستخدام:

```powershell
.venv\Scripts\Activate.ps1
```

4. شغّل الخادم:

```bash
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

5. افتح `http://127.0.0.1:8000` في المتصفح.
6. الصق مفتاح Gemini API، ثم ارفع صورة أو أدخل الكلمات. المفتاح لا يُكتب على القرص ولا يُحفظ في قاعدة بيانات، لكن يمرّ عبر الخادم إلى Google كي يُطلب المحتوى.

## استخدامه مع الهاتف

- من الموقع نزّل ملف `english_vocabulary.apkg`.
- انقل الملف إلى الهاتف أو افتحه مباشرة من التنزيلات.
- في Android، افتحه باستخدام AnkiDroid أو اختر الاستيراد من داخل التطبيق.
- في iPhone/iPad، افتح ملف `.apkg` باستخدام AnkiMobile.
- اختر الاستيراد؛ لن تحتاج إلى تثبيت إضافة Anki على الكمبيوتر.

## ملاحظات

- ملف `.apkg` هو الموصى به؛ فهو يضمّن ملفات الوسائط. ملف CSV تصدير نصي فقط ولا يضمّن الصور أو الصوت.
- إنشاء الصور والصوت يعتمد على توفر خدمات الإنترنت؛ قد تنجح صورة أو كلمة وتفشل أخرى. يمكن إعادة الضغط على زر تجهيز الوسائط لمحاولة العناصر الناقصة.
- استخدم مفتاح Gemini الخاص بك ولا تنشره أو تضعه في ملف عام. لا تُحفظ الكلمات في قاعدة بيانات ضمن هذا المشروع، لكن بيانات الطلب تُعالج مؤقتًا في ذاكرة الخادم.
- أعدّ المشروع رزمة Anki مستقلة بتنسيق `.apkg` دون الحاجة إلى Anki Desktop أو AnkiConnect.

## نشره على استضافة

ارفع مجلد المشروع إلى استضافة Python تدعم تطبيق ASGI، وثبّت `requirements.txt`، ثم شغّل:

```bash
python -m uvicorn app:app --host 0.0.0.0 --port ${PORT:-8000}
```

للنشر العام، استخدم HTTPS، وضع حدًا للحجم والطلبات، ولا تفعّل سجلات الخادم التي تسجّل أجسام الطلبات؛ لأن طلب Gemini يتضمن مفتاح API.
